Rien ne part à l’entraînement sans passer par ici. Une correction venue du web est un candidat, pas une donnée : elle se juge comme une proposition d’un collaborateur. Le projet ne couvre que le Fuuta Tooro — une forme juste dans un autre parler est à rejeter ici.

Les trois textes sont modifiables avant validation : l’aperçu sous chaque retour montre la paire {fr, pul} qui partira réellement dans le dataset. La sortie d’origine du modèle est conservée si vous la retouchez — c’est elle qui dit où le modèle se trompe.

Rejeter garde la ligne : la correction ne vaut rien, mais le texte source dit qu’un tour de phrase est demandé et que le modèle le rate — c’est la feuille de route du lot suivant. Supprimer efface pour de bon, à réserver aux insultes et au spam.
