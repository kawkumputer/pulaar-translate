Politique de confidentialité

Site www.pulaar-translate.com et application mobile Pulaar-Translate · mise à jour du 11 novembre 2026

Pulaar-Translate est un traducteur français ↔ pulaar, gratuit, porté par un projet bénévole. Cette page dit quelles données nous traitons, pourquoi, et comment les faire effacer.

Les textes que vous traduisez

Le texte est envoyé à notre modèle, hébergé sur Hugging Face, le temps de la traduction. Nous ne l'enregistrons pas. L'historique de l'application reste sur votre téléphone : il n'est jamais envoyé à nos serveurs.

Votre compte (application)

Vous pouvez utiliser l'application sans compte, dans une limite de quelques traductions par jour. Au-delà, la connexion avec Google ou Apple donne accès à une limite plus large. Le compte sert uniquement à compter vos traductions du jour. Nous recevons de Google ou d'Apple :

  • votre adresse e-mail (Apple permet de la masquer) ;
  • votre nom, si vous l'avez partagé ;
  • un identifiant technique.

Ces données sont stockées chez Supabase, notre fournisseur de base de données. Nous ne les vendons pas, ne les partageons avec personne et ne vous envoyons aucun message publicitaire.

Le compteur de traductions

Pour que le service reste gratuit pour tous, le nombre de traductions est limité chaque jour. Nous comptons les traductions par compte, par appareil ou par connexion. L'adresse IP et l'identifiant de l'appareil ne sont jamais stockés en clair : seule une empreinte chiffrée l'est. Ces compteurs sont effacés après sept jours.

Les retours sur les traductions

Si vous jugez une traduction ou proposez une correction, nous conservons le texte, la traduction, votre avis et, si vous le donnez, votre nom. Depuis l'application connectée, le nom de votre compte est repris quand vous n'en saisissez pas. Ces retours, relus à la main, peuvent servir à améliorer le modèle. N'y mettez pas d'information personnelle.

Mesure d'audience

Le site utilise Vercel Web Analytics, sans cookie et sans donnée personnelle.

Supprimer votre compte

Dans l'application, ouvrez Profil → Supprimer mon compte. Votre compte et vos compteurs sont effacés immédiatement. Vous pouvez aussi nous écrire à l'adresse ci-dessous. Les retours déjà envoyés restent, sans lien avec le compte supprimé.
